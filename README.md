# Test project (gitignored)

Run Claude Code from this folder with the plugin loaded from the repo:

    cd test
    claude --plugin-dir ..

Then:  /doable:doable-frontend build the landing page

Fill `client/START-HERE.md`'s Tier 1 items into `client/company.md` first (and drop media in `client/media/`).
Delete `.doable/`, `LANDING_PLAN.md`, `app/` etc. between runs to start fresh.
After editing the plugin files, restart claude or run /reload-plugins.
